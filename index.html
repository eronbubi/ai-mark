04 — Methodik

Wie der Index entsteht

Skala

Jede Kategorie wird auf 0–100 normalisiert. 100 heißt: bestmögliches beobachtetes Ergebnis, nicht „fehlerfrei“. Werte unter 40 markieren echte Schwächen, nicht nur Rundungsrauschen.

Index

Der AI-Mark-Index ist das arithmetische Mittel aller acht Kategorien: Index = Σ Punkte / 8. Keine Gewichtung — ein Modell kann sich nicht über eine einzige starke Disziplin nach oben retten.

Keine geschätzten Zahlen

Es wird kein Wert interpoliert, gerundet aus dem Bauch heraus oder aus Erinnerung ergänzt. Ein Modell ohne belegte Punktzahl bleibt aus dem Index draußen, statt mit einem Platzhalter aufzutauchen.

Modellbild

Jedes Modell bekommt eine eigene Signatur-Grafik. Sie wird deterministisch aus Modellname und Anbieterfarbe erzeugt — gleiches Modell, gleiches Bild, auf jedem Gerät.
